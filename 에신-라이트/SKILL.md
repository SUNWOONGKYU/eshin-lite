# /에신-라이트 — 경량 에이전트 제조 공장

> **라이트 = 사소·단순·저위험·로컬 1개 에이전트를 빠르게 만들고 자가검증으로 끝낸다.**
> "제대로·무겁게" 해야 하는 것(별도 Verification 에이전트·고위험 도메인·페르소나 토론·운영 감시·포털·배치)은 **라이트가 하지 않는다 — 그건 본체 `/에신`의 일이다.** 그런 신호가 보이면 만들다 멈추고 **본체로 라우팅**한다.
>
> ⚠️ **단, "라이트 = 막 만든다"가 아니다.** *싸고 필수적인 안전*(실호출 1회 검증·보안·BOM 안전진단·정직·승인·에스컬레이션 트리거)은 **그대로 한다.** 라이트가 줄인 것은 *무거운 검증 절차*이지 *기본 안전*이 아니다. 비중 있거나 위험하면 → 본체.

## ⚖️ 적용 대상 (L0에서 반드시 판정)

| 라이트로 OK | → 본체 `/에신`으로 (라이트 부적합) |
|---|---|
| 단일 책임·단순 입출력 · 1개 에이전트 | 여러 에이전트 묶음(배치) / 1호스팅=N(포털) |
| 외부 부품 거의 없음(기본 LLM 위주, 검증 부품 ≤2) | 검증 필요한 외부 부품 다수·복잡 인프라 |
| **저위험 전용** | **모든 고위험 도메인**(법률·의료·재테크·정치 등) — 면책·별도검증 필요 |
| 단발 · 단순 반복 · **가벼운 자가점검 루프(bounded ≤N)** | 복잡한 자율 루프·상태 머신·다중 에이전트 |
| 자가검증으로 충분한 *사소한* 산출물 | **비중 있는 산출물**(별도 Verification·엄격 검증 필요) |
| **로컬 웹 GUI**(`ui.py`+`ui/index.html`, 표준 라이브러리, 127.0.0.1 전용) 또는 CLI·파일 산출 | **웹 배포형·포털·서버 호스팅 UI**(외부 접속·인증·a11y 정식 검증 필요) |

→ **하나라도 오른쪽이면 본체 `/에신`.** 진행 중 오른쪽 신호가 생기면(부품 3개+·포털화·배치화·고위험·UI·비중↑) 즉시 **본체로 에스컬레이션**.

## 🚫 라이트도 절대 생략 안 하는 것 (싸고 필수)
단일 책임 · **자기완결**(외부 스킬·외부 AI 의무 호출 금지) · **보안**(시크릿 하드코딩·`eval`/`exec`·검증 없는 shell 금지) · 종료·비용 한도(반복형) · **승인 게이트(L2)** · **"파일 생성 ≠ 동작함"**(실호출 1회 검증) · **BOM 안전진단**(라이선스 불명·시크릿·미유지 부품 컷) · **출력 정직**(과장·허위 금지) · **에스컬레이션 트리거**(무거우면 본체로 — 이게 있어야 아래 "본체로 미룸"이 안전하다).

## 🔼 라이트가 하지 않고 본체 `/에신`으로 미루는 것 (V1.2)
- **별도 Verification 에이전트** — 라이트는 *자가* 실호출·정적 점검으로 종결(전역 규칙 "비중 있는 산출물은 별도 검증, **사소한 작업 제외**"와 일치). 별도 검증 주체가 필요할 만큼 비중 있으면 → 본체.
- **고위험 도메인 면책·출력정책 기계** — 라이트는 *저위험만* 만든다. 고위험이면 만들지 말고 → 본체.
- **깊은 검토**(페르소나 토론 5A/5B·review-evaluate 다회 루프·codex/Gemini 이중검증) → 본체.
- **운영 감시 루프**(에러율·사용률 임계값 모니터) → 본체/별도. 라이트는 "만들고 끝"(아래 L6 한 줄 메모만).
- **포털·배치·UI·웹 배포** → 본체.

## 💳 LLM 호출 비용 원칙 (제작 ↔ 런타임 분리 — 반드시 지킴)
**"에이전트를 만드는 것"과 "만들어진 에이전트가 돌아가는 것"은 완전히 별개다. 인프라 A/B는 *런타임*에만 해당하지, 제작과는 무관하다.**
- **제작·검증 LLM = 항상 구독(클로드 코드 본체).** 기획·조립·실호출 검증은 전부 로컬·구독으로. **A/B 불문, 제작·검증에 API 키·크레딧 사용 금지.** (검증하려고 API 호출 → 크레딧 벽에 막히는 사고 — 2026-06-14 고문서 해석 에이전트 회고.)
- **산출 에이전트의 런타임 LLM** = **B(로컬)→본인이 쓰면 `claude` CLI(구독 OAuth) 1순위**, 남에게 배포하면 그 사람 키. (포털 A·API 키 런타임은 본체 영역.)

## 공정 (L0 → L6) — 짧고 곧게

### L0. 시동 + 라이트 적합성 + 인프라
- 인자/맥락에서 제조 대상 도출. 위 적합성 표로 판정 — **부적합(고위험·포털·배치·UI·비중↑)이면 즉시 본체 안내하고 중단.**
- **인프라**: 항상 **B — 로컬 설치**(로컬 .py + LLM CLI). LLM은 **본인용 = `claude` CLI(구독) 기본**, API 키는 배포용만(💳 원칙). 작업 폴더 확정(`C:\Dev\agents\{name}\` 권장 — 한글·공백 없는 짧은 경로).
- **설치 위치 (V1.5 개정)** — 사용자가 **찾을 수 있는 곳**에 둔다. 폴더를 열면 `시작.bat` 이 바로 보여야 한다. 딥 경로에 묻는 것도, **바탕화면에 폴더·아이콘을 얹는 것도 하지 않는다**(V1.3 바로가기 폐지와 같은 취지 — 바탕화면은 사용자 공간). 설치 경로는 출하 보고에 명시해 사용자가 잃어버리지 않게 한다.

### L1. 요구 발굴 — 핵심 문답 (간소)
정체성 요소를 덮되 **짧게**. `AskUserQuestion` 선택지 우선, 모르면 "AI 추천".
- **★ Trivial Fast-Path**: 부품 0 · 저위험 · 단발 · 입출력 자명(예: 텍스트→텍스트 교정/요약/변환)이면 **문답 생략하고 한 줄 목표만 잡아 바로 L2(간이 승인)로.** (단순한 걸 질문으로 늘리지 말 것 — 2026-06-15 회고: 시간은 코드가 아니라 과잉 문답에서 샌다.)
- 그 외: 목표·이름 / 입력·출력·트리거 / 유형·루프 / 도구·LLM·메모리 / 제약·실패모드 / 종료·보안·비용 을 **꼭 필요한 것만** 1~5문. **고위험 감지 시 → 본체로.**

### L2. 간이 MBO 목표서 ⛔ (승인 게이트)
```
━━ 에이전트 제조 목표서(라이트) — {이름} ━━
🎯 목표: (한 줄)
🏷️ 이름·분류 · 📂 유형 · 🏗️ 인프라 B(로컬)
🧱 죽이는 수작업(AS-IS→TO-BE): (1줄)
📊 KPI: ① 호출 동작(의도대로 작동) ② 사용자 여정 1개
🤖 LLM: claude CLI(구독)→폴백 · 🛑 종료 · 🔐 보안 · 💰 한도
🧩 부품(BOM): (있으면 1~2개 + 라이선스, 없으면 "0")
━━ 승인하시겠습니까? ━━
```
⛔ 승인 없이 이후 단계 금지. (Trivial Fast-Path도 이 한 줄 승인은 받는다.)

### L2.5. 빠른 도메인 스캔 (선택, 가볍게)
필요할 때만: "① 같은 걸 푸는 기존 자산 있나(차별점) ② 표준/함정 1~2개" — WebSearch 2~3건, 3줄 요약. 자명하면 생략.

### L3. 발굴 + 간이 BOM 안전진단
- 기본 **LLM 단독**. 외부 부품이 꼭 필요할 때만 1~2개(공개저장소·OSS·사내자산). **데이터 API 부품 1개·잘 유지되는 라이브러리 1개는 라이트 범위(부품 ≤2).**
- **안전진단(필수·생략 금지)**: `eval`/`exec`·하드코딩 시크릿·deprecated·**라이선스 불명**·1년+미유지·한국어/보안 헌법 위반 → **🔴 컷**(되살리지 않음). 3분류 🟢적용 / 🟡재단 후 / 🔴컷. (예: `hanja` 라이선스 불명 🔴, Unihan kHangul 🟢.)

### L4. 제조 — 조립
- **system_prompt**(역할·동작·출력정책) + **에이전트 5대 요소 표준 구현**(아래) + **보안**·비용 한도.
  - **① 목표(Goal)** — system_prompt에 역할·출력 형식·규칙 명시
  - **② 두뇌(LLM)** — `claude` CLI(구독) 1순위 → `gemini` 폴백
  - **③ 도구(Tools)** — 입력 읽기·저장 등 실제 도구(해당 시). 없으면 "LLM 단독"임을 명시
  - **④ 메모리(Memory)** — 직전 결과 기억(작업기억, 수정 반복용) + 처리 이력 파일 누적(장기기억)
  - **⑤ 자율 자가점검 루프(Loop)** — 생성 직후 **출력 필수요소·요청 반영 여부를 스스로 점검해 부족하면 보완(bounded, 최대 N회·기본 3)**. ⚠️ *가벼운 자가점검까지가 라이트* — 복잡한 상태머신·다중 에이전트 루프는 본체.
- **결과 확인·저장 (필수, 생략 금지)** — "결과가 어디 있는지 못 찾는" 사고를 막는다.
  - **기본값 = 클릭 단계 없이 자동 저장.** 결과 파일을 에이전트 폴더에 바로 저장하고, 생성 완료 즉시 **기본 뷰어로 자동으로 연다**(`os.startfile(path)` — Windows). 저장 대화상자는 띄우지 않는다 (2026-07-07 실전: 대화상자 클릭 1회가 반복 실습에서 누적 시간을 늘림 — 자동 오픈만으로 "어디 있는지 못 찾는" 문제는 이미 해결됨).
  - 다른 위치에 저장하고 싶으면 열린 결과 파일을 사용자가 직접 복사·이동하면 된다 — 이 정도는 에이전트가 대신할 필요 없음.
  - 콘솔에도 최종 저장 경로를 굵게·구분선으로 눈에 띄게 출력한다. (GUI를 함께 낸 경우 화면에도 저장 경로 + "폴더 열기" 버튼을 둔다.)
- 산출 = **로컬 설치형 데스크톱 에이전트**. 반드시:
  - `engine.py` — LLM 호출 본체. **기본값 = `claude` CLI(구독) 1순위 → `gemini` CLI 폴백.** API 직접호출은 배포용만. 구독 강제 = `_sub_env()`로 `ANTHROPIC_API_KEY` 제거 후 호출, CLI는 `cwd=tempfile.gettempdir()`(세션로그 격리). 첫 줄 `sys.stdout/stdin.reconfigure(encoding="utf-8")`. 참조 구현(제작자 로컬 예시 — 경로가 없으면 위 서술만으로 충분): `{작업폴더}\{에이전트이름}\engine.py`.
    ⚠️ **Windows에서 CLI 경로는 `shutil.which()`로 찾고, 프롬프트는 명령행 인자가 아니라 `subprocess.run(..., input=prompt_text)`로 stdin 전달할 것.** `claude`·`gemini`는 npm 설치 시 `.cmd` 배치파일이라 Windows가 내부적으로 cmd.exe를 거쳐 실행하는데, 프롬프트에 HTML 태그 등 `<`·`>`가 있으면 인자로 넘길 때 cmd.exe가 리다이렉션 기호로 오인해 내용이 깨진다(2026-07-07 실전 확인). 같은 이유로 `stdin=subprocess.DEVNULL`도 피하고(입력 자체를 stdin으로 주므로 불필요), 인자 전달은 아예 쓰지 않는다.
  - `run.py` — 터미널 진입점(GUI 못 쓰는 환경 대비, 병행 유지. GUI를 내더라도 삭제하지 않는다).
  - `run.bat` — **터미널 전용 보조 진입점**(`run.py` 실행). `chcp 65001>nul` · `set PYTHONUTF8=1` · `set PYTHONIOENCODING=utf-8` · `pushd "%~dp0"` · `pause` · **한글 echo 금지**. ⚠️ GUI를 내는 경우(아래) 사용자에게 더블클릭하라고 안내하는 진입점은 `시작.bat` 하나뿐이다 — `run.bat`은 GUI 없는 환경(서버·SSH·접근성 도구)에서 터미널로 직접 돌릴 때만 쓰고 전면에 노출하지 않는다.
  - **★V1.3 로컬 GUI (인프라 B + 사람 개입형이면 기본 산출물)** — `ui.py` + `ui/index.html`. 파이썬 **표준 라이브러리만**(`http.server`) — Flask·FastAPI·Streamlit 도입 금지. `시작.bat`이 `ui.py`를 띄우는 **유일한 더블클릭 진입점**(이 경우 `run.bat`은 전면에 내세우지 않는다).
    **엔진 연동**: 기본은 `engine.py`를 모듈로 `import`해 함수 호출(같은 프로세스, 상태 공유 쉬움). 장시간 호출·크래시 격리가 필요하면 `subprocess` 분리 실행(이 경우 `ui.py` 종료 시 자식 프로세스 정리 필수). 라우트 계약·폴링/스트리밍 등 연동 규격 상세는 **본체 `/에신` SKILL.md 「★ V3.9 로컬 GUI(웹) 출하 표준」의 "`ui.py` ↔ `engine.py` 연동 규격" 참조.**
    **경량판에서도 생략 불가 (보안 항목 — 압축 대상 아님)**: ① **루프백 전용 바인딩** `ThreadingHTTPServer(("127.0.0.1", port), ...)`, `0.0.0.0` 금지 ② **토큰 인증 + 쿠키 승격** — 실행마다 `secrets.token_urlsafe(24)`, 최초 접속 `?t=<토큰>` → 쿠키(`HttpOnly; SameSite=Strict`)로 옮기고 `302`로 깨끗한 주소 ③ **경로 탈출 차단** — 작업 폴더 밖이면 `403`, 업로드 파일명은 `Path(name).name` + `[<>:"/\\|?*]` 치환.
    **화면 조판은 3단이 기본(권장)** — 좌(도구가 준비됐나) · 가운데(작업장) · 우(일이 어디까지 왔나). 양옆은 읽는 곳, 가운데는 하는 곳. 채울 게 없으면 억지로 3단을 만들지 않는다(빈 사이드바 금지).
    나머지 세부(고정 포트 폴백·덮어쓰기 금지·조용한 종료·favicon 204·종료 안내 / CDN 금지·시스템 폰트·라이트다크·tabular-nums·유의사항 블록·준비 상태 패널·업로드 3종·접근성·"AI 티" 금지 디자인)는 **본체 `/에신` SKILL.md 「★ V3.9 로컬 GUI(웹) 출하 표준」 참조.**
  - ⛔ **바탕화면 바로가기 자동 생성 금지** (V1.3 — 본체 V3.9 R7·R8 폐지 동기화, 운영자 판단 2026-08-01). `install_shortcut.ps1` 제조하지 않는다. 원하는 사용자 안내는 README 한 줄로만: "바탕화면에 두고 싶으면 `시작.bat` 을 오른쪽 눌러 「바로 가기 만들기」."

### L5. 자가 검토 + 실호출 검사 (자가검증으로 종결)
> 라이트는 *별도 Verification 에이전트를 쓰지 않는다*. 자가 점검으로 끝낸다. (비중 있거나 고위험이면 여기서 멈추고 → 본체.)
- **정적**: 시크릿 누출·`eval`·deprecated·구조 점검.
- **동적·실호출(필수)**: **실제 1회 호출**로 의도대로 작동 + 산출물 형식 확인("파일 생성 ≠ 동작함"). ⚠️ Windows에서 PowerShell 파이프(`$x | python`)는 한글을 깨뜨릴 수 있음 → **UTF-8 파일 + `cmd /c "chcp 65001 & python engine.py < in.txt"`** 로 검증.
- **간단 자가평가(5기준 약식)**: 목적 충족 · 품질·정합(설명·메타가 기능과 일치, 타 자산 복붙 0) · 리스크(실패모드 대응·자기완결 위반 0) · 실행성 · 정직(과장 0). 미흡하면 L4로 1회 회귀.
- 결함 회귀: 문구→L4 / 부품→L3 / 정책·KPI→L2.

### L6. 자산화·출하
- 설치 폴더에 engine·`run.py`·`run.bat`(터미널 전용 보조)·README 배치. 사람 개입형이면 `ui.py`·`ui/index.html`·`시작.bat`(유일한 더블클릭 진입점)·`requirements.txt` 추가 — 이 경우 사용자에게는 `시작.bat`만 안내한다.
- **★ 진입점 확인(필수)**: 폴더 안 `시작.bat` 더블클릭 → `ui.py` 기동 → 브라우저가 `http://localhost:{포트}` 로 열리고 주요 버튼이 실제로 눌리는지 확인. (GUI 대상인데 화면 확인 없이 "출하 완료" 금지 — "서버 200 ≠ 동작함".) 터미널 진입점(`run.py`)도 병행 유지.
- **더블클릭/실호출 재확인**으로 동작 확인.
- **포털 출시(DB·카드·페이지·배포) 안 함** — 필요하면 본체.
- **1줄 자산 기록**(`~/.claude/assets/자산-등재.md` — 진입점 경로 포함: 설치 폴더 + `시작.bat`).
- 출하 보고: 목표·KPI·진입점 경로(폴더 안 `시작.bat`)·실행 방법. **바로가기 경로 항목 없음**(V1.3 폐지 — 보고 필드를 채우려고 바로가기를 만들지 말 것).
